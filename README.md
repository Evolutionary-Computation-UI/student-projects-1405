# پروژه‌های دانشجویی درس محاسبات تکاملی — ۱۴۰۵

**University of Isfahan · Evolutionary Computation · Student Showcase**

این مخزن مجموعه‌ای از نسخه‌های **تأییدشده و داوطلبانه** پیاده‌سازی‌های دانشجویان است که **پس از پایان ارزیابی** منتشر می‌شوند.

## ساختار پیشنهادی

```text
exercise-1/
  github-username/
exercise-2/
  github-username/
exercise-3/
  github-username/
```

نام پوشه باید **نام کاربری GitHub** باشد؛ شماره دانشجویی و اطلاعات هویتی محرمانه منتشر نشود.

## مشارکت

1. پس از اتمام ارزیابی و تأیید امکان انتشار، این مخزن عمومی را Fork کنید.
2. در شاخه‌ای جدید یک پوشه در مسیر مربوط به تمرین ایجاد و نسخه پاک‌سازی‌شده کار را اضافه کنید.
3. README توضیحی، دستور اجرای آزمایش‌ها و وابستگی‌های نرم‌افزاری را ضمیمه کنید.
4. یک Pull Request باز کنید. ارسال PR به‌تنهایی به معنای پذیرش یا انتشار در شاخه اصلی نیست.
5. پس از بررسی کد و اطلاعات شخصی، مسئولان درس در صورت تأیید آن را Merge می‌کنند.

**هشدار:** Fork و Pull Request این مخزن عمومی هستند؛ کدها **پیش از Merge** نیز برای عموم قابل مشاهده خواهند بود. تنها پس از پایان ارزیابی و با رضایت آگاهانه مشارکت کنید.
